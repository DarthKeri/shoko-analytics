SHOKOLAD / SHOKO ANALYTICS 0.1.0

ЗАПУСК
Распакуйте весь архив и откройте ShokoAnalytics.exe. Папки app и runtime
должны оставаться рядом с EXE. Установка Python и Node.js не нужна.
Руководство: Shokolad_User_Guide_RU.pdf.
Требуется Windows 10/11 x64, WebView2 Runtime и .NET Framework 4.8.

ЕСЛИ ПРИЛОЖЕНИЕ НЕ ОТКРЫВАЕТСЯ
EXE автоматически создаст отчёт в папке diagnostics рядом с программой.
Если запись туда запрещена, используется папка данных Windows или TEMP.
Окно ошибки покажет путь; после ОК отчёт откроется в Блокноте.
В отчёте есть этап, код завершения, ошибки импорта и подробности сбоя.

ПРОВЕРКА ДВОЙНЫМ ЩЕЛЧКОМ
Закройте Shoko Analytics и откройте «Проверить запуск.cmd» рядом с EXE.
Дождитесь отчёта в Блокноте; тестовое окно может открыться и закрыться само.
Команды вводить не требуется. Передайте текстовый отчёт ответственному.
Проверка использует пустую временную папку. Настройки, исходные Excel,
CSV и Google-таблицы не изменяются. Отчёт не отправляется автоматически.

GOOGLE
В публичный архив параметры Google OAuth, входы, настройки и таблицы
не включаются. Для входа Google нужна отдельно настроенная сборка
от ответственного за приложение. В такой сборке достаточно кнопки входа.
CSV из Telegram скачивается вручную; фонового расписания в 0.1.0 нет.
