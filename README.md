# Shoko Analytics

Локальное Windows-приложение для подготовки и подтверждённого обновления Google-таблиц анализа автопарка.

Статус: MVP

## Пользовательский сценарий

Однократная настройка источников и тестовой Google-таблицы → ручной запуск → проверка источников → получение данных → предварительный просмотр → подтверждение → запись → сверка результата.

Ссылка на Яндекс Гараж может меняться перед каждым запуском. CSV получают через стороннего Telegram-бота от имени пользователя либо импортируют вручную.
