# Чёрный интерфейс Shoko Analytics

## Требования пользователя

Обновление требований от 13 октября 2026 года: только чёрная тема, ориентиры ChatGPT и GitHub. Всё, связанное с тестами и разработкой, находится на отдельной странице, которая доступна после включения соответствующей настройки. Технический журнал — многострочное текстовое поле с последовательными записями, как в Happ. Переключатель «Сценарий демонстрации» удалён полностью.

## Информационная архитектура

- Обновление: ссылка, дата, источники, проверка статуса, подготовка, просмотр, одобрение.
- История: пользовательские итоги запусков, без технических трассировок.
- Настройки: рабочие пути, подключения, переключатель «Показывать вкладку разработчика».
- Разработчик: технический журнал, диагностика, сведения о тестовом окружении. По умолчанию вкладка скрыта.

Скрытие диагностических элементов не отменяет ограничения записи: разработка продолжает использовать только разрешённые копии таблиц. Имя целевой таблицы остаётся на обычном экране, чтобы пользователь понимал, куда попадут данные.

## Визуальная система

Нейтральные чёрные поверхности, компактная боковая навигация, белая основная кнопка, тонкие разделители. Без градиентов, декоративных карточек, дополнительных метрик и фиолетового акцента. Типографика и контролы поддерживают регулярную работу с таблицами.

## Границы примера

Это локальный интерактивный пример интерфейса. Состояния проверок и записи имитируются; внешние сервисы и реальные файлы не используются. Функциональные проверки примера не являются проверкой Windows-сборки или интеграций.

## Подключённые скиллы

- openai/plugins: plugins/build-web-apps/skills/frontend-app-builder
- dobromirdikov/codex-frontend-design-skill: skills/frontend-design

Пакеты установлены в локальный каталог Codex. Первичный концепт создаётся Image Gen, затем интерфейс собирается из HTML/CSS-контролов. Растровая картинка не используется вместо работающего интерфейса.

## Проверка визуального примера

Проверено в Codex IAB: скрытие/включение вкладки разработчика, текстовое поле журнала и добавление записей, валидация пустой ссылки, подготовка, оба режима просмотра, единое подтверждение записи, результат в истории. Ошибок в журнале браузера при проверке не обнаружено. Проверены ширины 1505 и 390 px, размер браузера восстановлен.

Концепция Image Gen и последний снимок браузера просмотрены через view_image в одной проверке. Сверены пять аспектов: нейтральная чёрная палитра, навигация, поля ссылки/даты, строки источников, основные действия. Исправлено отсутствие иконок в раннем снимке после загрузки ресурсов. Подписи основной страницы соответствуют концепции; детали исходных значений остаются демонстрационными.

Осознанные отличия от растровой концепции: более компактная высота и размеры текста для ежедневной работы; штатный календарь браузера отображает дату по своей локали; режим разработчика и дополнительные экраны реализованы по требованиям пользователя в той же визуальной системе. Это предварительный макет, не утверждённая пиксельная копия и не рабочая Windows-сборка.
