# Активность приложения — 0.1.0

Страница «Обновление» использует согласованный широкий макет: «Запуск / Источники», поле «Ошибки» сразу под вкладками, график, дата обработки и кнопки «Проверить статус / Обновление». Пути и подробные результаты проверок остаются в «Источниках». Окно по умолчанию — 1280 × 820, длинные страницы прокручиваются внутри окна.

График показывает 14 календарных дней по московскому времени. Переключатель «Линии / Столбцы» находится справа сверху графика. Выбор хранится как `chart_type` в единственном `settings.local.json`, сохраняется сразу и не завершает первичную настройку. Он не меняет источники, проверки или просмотренный план; это поле исключено из контрольной суммы настроек для записи.

Запуск учитывается один раз при создании рабочего экземпляра приложения, до появления первой записи о запуске в журнале. Для старых установок исходные значения однократно восстанавливаются из точных сообщений запуска в `logs/application.log`. Далее дневные суммы хранятся локально в `logs/activity.json`. Опрос интерфейса, проверки источников, подготовка, штатные `--smoke` и `--ui-smoke` не добавляют запусков. Повреждение или запрет сохранения статистики сообщаются на графике и не блокируют основную работу; повреждённая статистика не заменяется пустой.

Обновления вычисляются по всем сохранённым `plans/*.result.json`, а не по ограниченному списку последних 100 операций интерфейса. Учитывается только `status=done`: подтверждённая запись успешно прошла сверку. Для новых операций используется `completed`, записанный после сверки; для старых успешных результатов без этого поля используется `created`, поскольку точное время завершения раньше не сохранялось. Дата обработки Excel не подменяет дату фактического обновления. Ошибки, прерванные операции, подготовленные планы и обновления без записи не учитываются.

Сведения о работе остаются в выбранной рабочей папке. График не обращается к внешним сервисам. Полный Google-бекап, BF-копии изменяемых листов, предпросмотр и подтверждение записи сохранены.

Проверка изменения: 229 автоматических тестов на Python поставки — 228 прошли, один пропущен (Windows запрещает создание тестовой символической ссылки). Проверены импорт старого журнала без повторного подсчёта, московская граница суток, более 100 завершённых операций, исключение неуспешных операций, перезапуск и сохранение вида, отсутствие счётчиков у smoke-запусков и полный локальный цикл с подтверждением/копией/сверкой после переключения вида.

В браузере проверены оба графика, сохранение вида после перезагрузки, «Источники», проверка статуса, обе темы, размеры 1440/768/390 без горизонтального переполнения. Проверки используют отдельный синтетический профиль и локальные Excel, внешние HTTP-запросы запрещены на стенде. Дополнительно проверен запуск EXE и отдельного окна WebView2. Пользовательские таблицы и сохранённый Google-вход в этих проверках не используются. Новая живая запись в Google в рамках изменения не выполнялась.
