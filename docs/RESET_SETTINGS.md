# Удаление настроек — 0.1.0

«Настройки → Общие → Удалить все настройки» открывает подтверждение. «Отмена» и Escape закрывают окно без сброса. После подтверждения приложение очищает пути к Excel/CSV и Google-ключам, выбранную таблицу, папку Google-копий, разрешённую тестовую цель, дату, вид интерфейса, вид графика и режим разработчика. Сохранённый локальный вход Google удаляется; сам Google-аккаунт и его облачные разрешения не удаляются.

Вместо текущего содержимого единственного `settings.local.json` атомарно сохраняются исходные значения. Другие файлы настроек и их копии не создаются. Рабочая папка и её locator, исходные документы (в том числе внешние credentials/OAuth JSON), резервные копии, результаты операций, статистика и журналы сохраняются. Подготовленный план, результаты проверок и экранная история переходов очищаются, открывается мастер первичной настройки. Старое подтверждение записи использовать нельзя.

Сброс запрещён при подготовке, записи, проверке и подключении Google. API требует строгое `confirmed=true`. При ошибке удаления Google-входа настройки сохраняются; если вход уже удалён, а файл настроек недоступен для записи, сообщение прямо сообщает о частичном сбросе. Ни один из этих случаев не оставляет пригодным прежний подтверждённый план.

Проверки: 6 новых автоматических тестов на подтверждение/занятость, сохранность файлов и копий, запрет старого плана, повторный запуск и ошибки доступа. Полный набор на Python поставки: 235 тестов, 234 прошли, один пропущен из-за ограничения Windows на символические ссылки. В браузере на отдельном пустом профиле проверены отмена, подтверждение, переход к мастеру и его повторное открытие после перезагрузки. Пользовательские настройки и Google-вход при разработке не сбрасывались. Версия — 0.1.0, прежний EXE-запускатель сохранён.
