# Источники данных

Сведения получены статическим чтением локального архива ScriptExcel. Работоспособность и соответствие готовых EXE исходникам не проверены.

## Основной legacy-скрипт

update_google_sheets.py читает Средние_цены_простои_{год}.xlsx, лист Кол_состав_{месяц}-{год}, загружает Google-лист «Простои», затем показатели «Предложения цен». Начисление_{месяц}-26.xlsx, лист за вчера, загружается в «Новый старый водитель» и используется для счётчика H.

Целевые колонки: F/G из D/C «Простоев»; P/Q/R/S/U/V/W/X — показатели за вчера; Y/Z и AB/AC — исторические показатели на дату запуска минус 7/14 дней. Есть специальные правила для Polo и Octavia 2019. Полное соответствие должно быть сверено с эталоном до реализации.

update_garage.py читает последний изменённый CSV рядом с программой и заменяет Google-лист «Выгрузка_Бот_Гараж». Последующий перенос делает скрипт внутри Google-таблицы: его правила пока неизвестны.

## Другие варианты

- Прмказ_цены.rtf: Приказ_цены_2026.xlsx → F/G.
- акционные водители.rtf: начисления, модель AM, год AO, признак заполненного H → H целевого листа.
- Начисления.rtf: лист Кол_состав начислений → выбранные показатели P:AC.
- analyses.txt: сводная книга, листы «приказ цены», «н_ст_вод», «Простои»; последняя дата каждого листа и исторические смещения 6/13 дней.

Эти варианты нельзя объединять без согласования различий.
