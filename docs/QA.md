## Google HTTPS и проверка статуса — 0.1.2

- **49 автоматических тестов**: дополнительно проверены системное доверие Windows с обязательной проверкой сертификата/имени узла, различение TLS/таймаута/соединения/авторизации, исключение секретов из сообщений и получение только метаданных при проверке статуса Google.
- Реальная причина прежнего сообщения «нет соединения или таймаут» — `SSLCertVerificationError: self-signed certificate in certificate chain`. Через системное хранилище сертификатов Windows чтение метаданных предоставленной тестовой копии вернуло HTTP 200. Исправление использует truststore 0.10.5 на старте Windows-приложения; проверка подлинности HTTPS включена.
- В собранном EXE до финального облегчения статуса прошли проверки предоставленных Excel, ручного CSV и доступа к Google-копии. CSV содержит 21 строку данных. Запущенная подготовка отменена по просьбе пользователя о самостоятельном тестировании; запись в Google не запускалась. В Git не включаются ключ, идентификатор пользовательской копии, реальные данные, планы или локальные настройки.
- Финальная проверка статуса Google использует только метаданные таблицы и наличие листа «Предложение цен». Содержание ячеек и снимок для резервного копирования по-прежнему читаются при подготовке/подтверждении; это может занимать больше времени, чем проверка доступа.
- Финальное тестирование на пользовательских данных выполняет пользователь. Проверка настоящей записи в Google и Telegram остаётся отдельной приёмкой.
