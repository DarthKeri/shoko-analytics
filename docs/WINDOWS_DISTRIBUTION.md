# Поставка Windows 0.1.0

Пользователь запускает прежний ярлык или ShokoAnalytics.exe. Интерфейс, рабочая папка, settings.local.json и DPAPI-вход Google сохраняют прежнее устройство. Python и Node на компьютере пользователя устанавливать не требуется.

В папке ShokoAnalytics находятся:

- ShokoAnalytics.exe — небольшой запускающий EXE на C# / .NET Framework, без упаковщика; версия файла и продукта 0.1.0. Он запускает только поставляемые runtime/pythonw.exe и app/bootstrap.py → app/main.py, передаёт аргументы с Windows-экранированием и ожидает завершения окна. Ранние ошибки, отсутствие файлов и аварийное завершение сохраняются в диагностический отчёт; успешный выход не оставляет ложного отчёта.
- runtime — официальный embeddable Python 3.13.16 x64 с закреплёнными библиотеками. Python.exe, pythonw.exe и python313.dll проверяются по Authenticode-подписи Python Software Foundation. Загрузка архива проверяется по опубликованному SHA256.
- app — обычные Python-исходники, готовый React-интерфейс и иконка. Самораспаковки, скрытого загрузчика и шифрования исполняемого кода нет.
- build-manifest.json — SHA256 поставленных файлов и происхождение Python; упаковщик проверяет манифест перед заменой установленной папки. Изменённый, неполный или дополненный посторонними файлами кандидат отклоняется.

Запускающий EXE Shoko не имеет собственной Authenticode-подписи. Подпись Python не является подписью нашего приложения. Запуск выполняется с правами текущего пользователя, без запроса администратора. Изолированный Python не зависит от PATH, системной установки Python или пользовательских модулей. Во время запуска нет установки библиотек, загрузки приложения из сети или изменения Kaspersky. Настройки, сессии, таблицы и журналы пользователя в дистрибутив не включаются.

Сборка: tools/build.ps1 → Vite → tools/build-portable.ps1 → тесты на точном вложенном Python → запуск EXE с --smoke в папке с пробелами и кириллицей → сверка файлов → перенос готовой папки в dist/ShokoAnalytics. Предыдущая папка сохраняется в build/previous-distribution-*. Если перенос кандидата не удался, прежняя папка возвращается. Публикация создаёт ZIP и SHA256SUMS.txt. Все операции ограничены build/dist этого репозитория; рабочая папка данных не переносится.

Исходная проблема: прежний PyInstaller EXE получал PDM:Trojan.Win32.Generic после работы с сохранённым Google-входом и чтения метаданных. При сравнении тот же код на обычном Python и кандидат новой поставки прошли чтение тестовой таблицы и папки копий с последующим polling под активным Kaspersky. Это подтверждает совместимость проверенного сценария в текущей среде; внутреннюю причину решения Kaspersky журнал не раскрывает. Прохождение одного сценария не гарантирует отсутствие будущих детектов или иной политики на другом ПК.

Исключения, доверенные программы и настройки защиты не добавлялись. Локальный скан KES ранее был запрещён корпоративной политикой; успешный файловый скан не заявляется. Файлы в Kaspersky или другие службы анализа не отправлялись. Копирование Google, запись значений и изменение исходных пользовательских настроек в антивирусной проверке не выполнялись.

Официальные источники: [Python для поставки вместе с приложением](https://docs.python.org/3.13/using/windows.html#the-embeddable-package), [Python 3.13.16, файлы и SHA256](https://www.python.org/downloads/release/python-31316/). Публичный GitHub-релиз v0.1.0 обновлён поставкой с отдельным Python. Параметры Google OAuth в публичный архив не входят; настроенные сборки для сотрудников распространяются отдельно. Руководство пользователя и SHA256 доступны в Assets релиза.


В поставку входят app/startup_diagnostics.py, «Проверить запуск.cmd» рядом с EXE, README-FIRST.txt и руководство PDF. [Диагностика запуска](STARTUP_DIAGNOSTICS.md) описывает расположение отчётов, изоляцию тестовых профилей и внешние ограничения.
