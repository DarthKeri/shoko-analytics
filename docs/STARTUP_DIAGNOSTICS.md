# Диагностика запуска 0.1.0

## Автоматический отчёт

C# EXE создаёт контекст отчёта до проверки наличия Python и до запуска процесса. При отсутствии файлов, отказе Process.Start или ненулевом коде завершения он сохраняет UTF-8 отчёт: время, Windows/CLR, комплектность, этап EXE, последний этап Python, код в десятичном и шестнадцатеричном виде, ограниченные stdout/stderr и traceback.

Папки перебираются по доступности записи: diagnostics рядом с EXE, %LOCALAPPDATA%/ShokoAnalytics/diagnostics, %TEMP%/ShokoAnalytics/diagnostics. Каждый запуск получает уникальное имя. При успешном завершении временные подробности удаляются; штатный запуск не помечается как ошибка. После ошибки показывается путь и по ОК открывается Блокнот.

bootstrap.py и startup_diagnostics.py используют стандартную библиотеку до импорта truststore, ядра, pythonnet и WebView2. Стадии загрузки позволяют отличить раннюю ошибку импорта, рабочую папку, настройки и запуск WebView2. Faulthandler помогает сохранить стек при поддерживаемом Python аварийном завершении; код завершения фиксирует EXE даже при отсутствии traceback.

## Ручная проверка без команд

«Проверить запуск.cmd» входит в каждую поставку рядом с ShokoAnalytics.exe. Он вызывает подписанный встроенный python.exe и app/startup_diagnostics.py, поэтому может собрать базовый отчёт и при проблеме самого EXE. При отсутствии Python CMD сообщает об этом и коде завершения в отдельном текстовом файле. Отчёт открывается в Блокноте, ручной ввод не требуется.

Проверяются SHA256 манифеста, обязательные файлы и структура папок, зарегистрированные WebView2/.NET, импорты, структура JSON настроек без вывода значений. Backend и окно проверяются на отдельных пустых временных профилях. Реальные таблицы не открываются; HTTP-запросы Google не выполняются. Тестовое окно закрывается автоматически, ожидание ограничено.

## Данные и ограничения

Содержимое настроек, сессии, OAuth-конфигурация и таблицы не собираются. Из traceback не извлекаются локальные переменные. Типовые secret/token/password/Bearer/JWT значения и параметры URL маскируются; домашний путь скрывается. Размеры потоков и подробностей ограничены. Отчёт не отправляется автоматически; перед передачей его можно просмотреть.

Если Windows или защита организации вообще запрещает исполнение EXE и скриптов, либо недоступны все папки записи, приложение не может гарантировать создание собственного отчёта. Диагностика не отключает защиту, не обходит политики запуска, не исправляет файлы и не устанавливает компоненты.

Диагностика не определяет по одному коду завершения, виноват ли антивирус: это сверяют с событиями защиты на конкретном компьютере. Версия сохраняется 0.1.0.

Текст отчёта, названия этапов и итоги проверок выводятся по-русски в UTF-8 независимо от кодировки Windows. Названия исключений, модулей и исходный traceback сохраняются для диагностики.
